# Competitive research (reference only)

Brief landscape notes for Camacho POS Colombia commercial positioning. **Do not copy copy, visuals, or UX patterns** from these vendors.

| Reference | Notes for differentiation |
| --- | --- |
| Alegra | Cloud accounting + POS leanings; Camacho emphasizes local-first caja and kit hardware. |
| Siigo | Strong Colombia SME accounting/fiscal ecosystem; Camacho integrates fiscal via adapters, does not redefine DIAN domain in the commercial site. |
| Vendty | Regional POS SaaS; contrast with offline-capable POS Local Service + explicit capability statuses. |
| Loggro | Multi-vertical retail suites; Camacho publishes sector pages with certification honesty, not fake feature parity. |
| Fudo | Hospitality-oriented POS; Camacho focuses retail/pharmacy/bakery kits rather than restaurant floor UX. |
| Square | Global payments+POS brand; Camacho is Colombia-specific licensing, COP pricing, and Central Authority roles. |
| Shopify | Commerce platform with POS add-ons; Camacho is not inventing a web cashier — Electron/Android after hire. |

Use this list only to avoid overclaiming and to keep messaging specific. Product truth remains contracts, API feature statuses, and installed POS apps.
