# Competitive research (reference only)

Brief landscape notes for Camacho POS Colombia commercial positioning.  
**Do not copy copy, visuals, UX patterns, or proprietary documentation** from these vendors.

Analysis is original positioning guidance for this portal. No scraped pages, no invented market-share numbers.

| Reference | Category | Differentiation angle for Camacho |
| --- | --- | --- |
| **Alegra** | Cloud accounting + light POS leanings (LatAm) | Camacho sells local-first caja + hardware kits; accounting is not the hero of the commercial site. |
| **Siigo** | Colombia SME accounting / fiscal ecosystem | Camacho integrates fiscal via POS adapters; the portal must not redefine DIAN rules or impersonate Siigo workflows. |
| **Vendty** | Regional POS SaaS | Contrast offline-capable POS Local Service and explicit `AVAILABLE` / `IN_CERTIFICATION` / `COMING_SOON` badges — no fake feature parity. |
| **Loggro** | Multi-vertical retail suites | Sector pages (`/soluciones/*`) stay honest about certification; avoid “all verticals complete” claims. |
| **Fudo** | Hospitality-oriented POS | Camacho commercial focus is retail / pharmacy / bakery kits, not restaurant floor UX clones. |
| **Square** | Global payments + POS brand | Camacho is Colombia-specific licensing, COP integer pricing, and Central Authority roles — not a Square clone. |
| **Shopify POS** | Commerce platform with POS add-ons | Camacho is not inventing a web cashier for store checkout; Electron/Android remain product-line surfaces after hire. |

## How to use this folder

1. Keep notes short and attributable to public marketing categories only.
